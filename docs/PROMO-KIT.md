# 宣传物料 · Promo Kit

面向「出门穿什么」v1.0.0（Android APK）。图片提示词可直接投喂 Midjourney / DALL·E / 即梦 / 可灵等；
文案按渠道分了长度，避免一份走天下。

> **先读这段（很重要）**：下面的图与文案都**刻意避开了我们实现不了的东西**——
> 不承诺自动识别身材、不承诺时尚建议库、不承诺"AI 帮你想搭配"。这个 App 做的是
> **在你已有的几套衣服之间替你排序**。宣传一旦越过这条线，用户装上就会觉得被骗。
> 具体见文末「不能写的宣传点」。

## 一、图片提示词 · Image prompts

统一风格要求（每条都带上，保证一套图看起来是一家人）：
> 现代极简风、柔和自然光、真实摄影质感、低饱和暖色调、大量留白、无文字无 logo、
> 中国年轻女性日常场景、9:16 竖版（应用商店/小红书）或 1:1 方版（朋友圈/推特）。

*Shared style tail for every prompt: `contemporary minimalist, soft natural daylight, realistic photographic texture, low-saturation warm palette, generous negative space, no text, no logos, East Asian young woman in everyday setting, vertical 9:16`*

**English**
```
A woman in her mid-twenties stands in front of an open wardrobe, a beige knit sweater in one hand
```

## 二、文案 · Copy

### 2.1 应用商店 / 短描述（≤ 80 字）

**主推**
```
出门前站在衣柜前挑不定？拍 1–4 套衣服，选好场合，App 立刻给出排名。
照片只留在手机内存里，看完即弃；API Key 也只存你这台设备。
```

**备选（更强调速度）**
```
别再试穿三遍才出门。拍下你在犹豫的那几套，选好场合，几秒内看到哪套最合适。
照片不上传、不留存。
```

**English (for GitHub / store listing)**
```
Can't decide what to wear? Snap 1–4 outfits, pick the occasion, get a ranking in seconds.
Photos never leave memory; API keys never leave your device.
```

### 2.2 一句话定位（做海报/头图用）

```
拍照 → 排名 → 出门。中间不需要纠结。
```
```
它不教你怎么穿，只帮你在已有的几套里选一套。
```

第二句更重要 —— **主动划清边界**反而更可信，也更能筛掉会失望的用户。

### 2.3 小红书 / 朋友圈（长文，带真实感）

```
【我做了个东西治自己的"出门前选择困难"】

每次出门前都要把两套衣服轮流穿上、照镜子、再换回来，来回三遍，最后还是穿回第一套。
不是没有衣服，是每次都决定不了。

所以我做了个 App：把你正在犹豫的那 1–4 套拍下来，选一下今天什么场合、
什么天气，几秒钟就给你一个排名，告诉你哪套最合适。

几个我自己很在意的点：

· 它不"评价"你。分数只反映照片里看得见的东西 —— 看不清的地方它会说看不清，
  不会瞎猜你的身材、职业、年龄。
· 照片不进任何服务器。原图只在内存里过一遍就丢掉，历史记录里只有文字和分数。
· 不联网也能跑：可以挂一个本地的决策模型（Laya），完全离线，一分钱不花。
· 它不教你穿搭。它只在你已经有的几套里帮你排序 —— 我不想做一个对我说教的东西。

顺手做了个"拍摄引导"：逆光、只拍半身、镜子没擦，都会让分数偏低，
而你会以为是 App 不准。拍之前看一眼那 6 条，结果会准很多。

现在只有 Android 版，装上后要自己配一下模型地址（三条路，最省事的是填地址+一个口令）。
不是开箱即用的东西，这点我先说清楚。

#穿搭 #选择困难 #极简生活 #独立开发
```

**为什么这么写**：主动交代"不是开箱即用"和"不教穿搭"，会**降低转化但提高留存**——
比起装完就删，我更希望留下的人知道自己在用什么。

### 2.4 产品介绍（GitHub / 官网，正式）

```
出门穿什么 · Outfit Decider

【它解决什么】
出门前的穿搭选择困难。真正需要的不是"被分析"，而是在 30 秒内定下来穿哪套。

【怎么做】
拍 1–4 套衣服 → 选场合/天气/风格 → 得到排名。

两条并行的链路，你可以只用其中一条：
· 快速评分：6 个维度（综合/美观/场合/身形/风格/实用），0–5 分一位小数，
  **只给数字，不给任何解释文本**。手机上没人愿意读一大段再自己做决定。
· 深度分析：多模态模型看原图，出三段式报告（排名 → 逐套优点与不足 → 整体建议）。
选「两个都要」时，快速排名先出现，深度报告在后台补上，不用干等 20–40 秒。

【三条接模型的路】
1. 中转服务：部署一个自带上游 Key 的服务，App 只填「地址 + 一个口令」。
   适合把 App 给不折腾的人用。
2. 直连 TypeSafe JEv：不需要电脑，用你自己的 API Key。
   （但 JEv 不生成文本，需要再配一个能看图的模型来做图片描述。）
3. 自建 Laya 本地引擎：开源的 System 1 决策引擎，可完全离线、零成本。
   实验性 —— 我们实测它单独排序接近掷硬币，需要搭配多模态纠正才有价值。

【隐私是硬约束】
· 原图只进内存，看完即弃：不写盘、不入库、不进历史。历史只有文字与分数。
· API Key 只存设备钥匙串，不进代码、日志或任何报告。
· 无埋点、无遥测：除你配置的地址外，App 不发任何出网请求。

【诚实说明】
· 首次使用必须自己填模型地址（内置 127.0.0.1 在真机上指手机自己，是错的）。
· Laya 档位需要一台电脑常驻，且是实验性的。
· 深度分析要 15–37 秒。
· Android 版已可安装；iOS 未构建。

源码与完整规格：https://github.com/bo-830/outfit-decider
```

## 四、不能写的宣传点 ⚠️

这些**实现不了**，写进宣传会直接掉信誉：

| 不能写 | 为什么 |
|---|---|
| 「AI 帮你搭配出新造型」 | 它只在**你已有的几套之间排序**，不生成搭配 |
| 「自动识别你的身材/适合你的版型」 | 只基于照片可见内容；看不清就说看不清，不臆测身材 |
| 「上传照片分析」 | 照片**不上传**（除非你自己配的中转/云模型，那也是你在用） |
| 「海量时尚数据库 / 专业造型师建议」 | 没有这东西 |
| 「一键出门 / 开箱即用」 | 首次必须自己填模型地址 |
| 「秒出结果」 | 深度分析 15–37 秒；只有快速评分是秒级 |
| 「iOS 版」 | 只构建了 Android |
| 「免费」 | 取决于你选的模型：自建 Laya 是 $0，JEv 云端按量计费 |

## 五、可以强调的真实优势

| 可以写 | 依据 |
|---|---|
| 照片只进内存，不留存 | 硬约束，有测试断言 |
| Key 只存设备钥匙串 | SecureStore；web 降级会明确提示 |
| 无埋点无遥测 | 除配置地址外无出网请求 |
| 可完全离线、零成本运行 | 自建 Laya 档位 |
| 快速评分只给数字、不废话 | System One 的硬约束 |
| 拍摄引导能提高准确率 | 逆光/半身/镜子脏确实会让分数偏低 |
| 深度分析失败不会顶掉快速结果 | 渐进结果，已实测 |
