# 真实穿搭照片生成提示词（给豆包 / 图像模型用）

用途：生成**真实感**的穿搭照片，用来验证「Laya 打分 + 多模态纠正」这套判断到底准不准。
之前的夹具是抽象扁平插画，只能证明链路通，**不能证明判断准**——这批图就是为了补上这一环。

## 怎么用

1. 把下面每个提示词丢给豆包（或任意图像模型）生成，每套**生成 1 张**。
2. 建议统一 **竖构图 3:4、全身入镜、正面站立、室内自然光**，这样不同套之间可比。
3. 生成后按文件名放回来（见每条的「建议文件名」），路径：
   `outfit-decider/fixtures/images-real/`
4. 回给我之后，我会用它们跑同一套对照评估（`laya_only` vs `laya_review`），
   看纠正能不能把"明显不合适"和"明显合适"分开——这才是真实准确度的证据。

## 每套的「预期答案」

我特意成对设计：**同一场合下，一套明显合适、一套明显不合适**。
这样评估才有客观标尺，而不是靠我主观说"它答得对不对"。

## 生成时的注意事项

1. **不要修图美化**：要真实感，保留皮肤纹理与自然光影。过度精修的图会让模型看到"完美"而无法反映真实衣物差异。
2. **人物尽量同一人**：同一组内（A1/A2）最好看起来是同一人，这样"换了什么衣服"是唯一变量。
3. **背景保持简单**：白墙/纯色/虚化背景，避免背景元素干扰模型判断。
4. **全身必须完整入镜**：脚部不能裁掉——鞋履是评分维度之一。
5. **A2、B2、C2、D2 也不要故意拍得丑**：只是"衣服不适合场合"，人本身要正常、体面。否则模型可能因为"照片质量差"而给低分，那就不是判断衣服了。
6. 如果豆包一次只出半身，可在提示词末尾加强：`必须包含完整全身与双脚，竖构图 3:4`。
